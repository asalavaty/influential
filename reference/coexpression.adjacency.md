# Adjacency matrix

The adjacency matrix of a co-expression network of lncRNAs and mRNAs in
lung adenocarcinoma that was generated using igraph functions

## Usage

``` r
coexpression.adjacency
```

## Format

A data frame with 794 rows and 794 variables:

- lncRNA:

  lncRNA symbol

- lncRNA:

  lncRNA symbol
