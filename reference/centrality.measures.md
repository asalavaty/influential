# Centrality measures dataset

The centrality measures of a co-expression network of lncRNAs and mRNAs
in lung adenocarcinoma

## Usage

``` r
centrality.measures
```

## Format

A data frame with 794 rows and 6 variables:

- DC:

  Degree Centrality

- CR:

  ClusterRank

- NC:

  Neighborhood Connectivity

- LH_index:

  Local H-index

- BC:

  Betweenness Centrality

- CI:

  Collective Influence
