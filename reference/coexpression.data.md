# Co-expression dataset

A co-expression dataset of lncRNAs and mRNAs in lung adenocarcinoma

## Usage

``` r
coexpression.data
```

## Format

A data frame with 2410 rows and 2 variables:

- lncRNA:

  lncRNA symbol

- Coexpressed.Gene:

  Co-expressed gene symbol
